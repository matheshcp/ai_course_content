Lab intro

Data Quality Track: From Dirty Warehouse Export to Clean CSV

Scenario: Warehouse hands you warehouse_messy_data.csv — 1000 rows of product inventory with mixed-case names, Quantity as "two hundred" / "NaN", missing prices, inconsistent Status. Clean it with a reproducible pipeline and report stock value by Category. You will learn: string normalisation, numeric coercion with fallbacks, date parsing (dd/mm/yyyy), validation rules, writing a cleaned CSV. Time: ~60 minutes. Level: Beginner–Intermediate. Needs: Python 3.8+ (pandas optional). Env: 🟢 Colab only.
