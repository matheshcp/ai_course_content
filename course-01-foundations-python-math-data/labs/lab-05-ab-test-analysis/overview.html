Lab intro

Experimentation Basics Track: Rates, Z-Test, Ship/No-Ship

Scenario: ab_test.csv logs 294,478 sessions with con_treat (control/treatment), page, converted (0/1). Compute conversion rates, a two-proportion z-test, a 95% CI, and a minimum detectable effect — then conclude whether to ship. You will learn: group-by rates, standard error, z-test (manual or scipy), power sketch, peeking pitfall. Time: ~50 minutes. Level: Intermediate. Needs: pandas + math/scipy. Env: 🟢 Colab only.
